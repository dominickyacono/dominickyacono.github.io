# Dominick Yacono — personal website

A responsive, static portfolio for GitHub Pages. No build tools or dependencies required.

## Publish

1. Create a public repository named `dominickyacono.github.io` under `dominickyacono`.
2. Add `index.html`, `columbus.jpg`, `pittsburgh.jpg`, and `.nojekyll` to its `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**, and save.
4. After deployment completes, visit https://dominickyacono.github.io/.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Edit

All text and styling live in `index.html`. Edit and commit that file to update the site.
The Chicago dashboard preview is served from its existing GitHub image URL. Skyline photos are included locally.
